# 📊 DB Lab 6 – Data Aggregation using GROUP BY and HAVING

## 📖 Overview

This repository contains SQL queries demonstrating data aggregation techniques using GROUP BY and HAVING clauses.

The lab focuses on analyzing relational database tables such as Student, Faculty, Course, and Enrollment to generate summarized reports using SQL aggregate functions.

## 🎯 Objective
Understand SQL aggregate functions
Learn how to use GROUP BY to organize data into categories
Apply HAVING to filter grouped results
Perform analytical queries on relational databases
Combine JOIN with GROUP BY for meaningful reports

## 🧠 Concepts Covered
Aggregate Functions
Function	Description
COUNT()	Counts number of records
SUM()	Calculates total value
AVG()	Calculates average value
MAX()	Finds highest value
MIN()	Finds lowest value
GROUP BY Clause
