# 📘 DB Lab 5 – Data Retrieval from Multiple Tables Using JOINs
## 📌 Lab Description

This lab is designed to strengthen understanding of relational databases by retrieving meaningful information from multiple related tables using INNER JOIN operations. It emphasizes correct usage of primary–foreign key relationships and table aliases while keeping the database structure unchanged.

## 🎯 Objectives

Learn why JOIN operations are essential in relational databases

Retrieve data from two or more related tables using INNER JOIN

Apply proper JOIN conditions to ensure accurate results

Use table aliases for better query readability

Perform analytical queries without modifying stored data

## 🧠 Key Concepts

Relational database design

INNER JOIN and JOIN conditions

Primary key and foreign key relationships

Joining multiple tables in a single query

Sorting, filtering, and aggregation with JOINs

## 🗂️ Lab Breakdown

Part A: Student and Enrollment relationships

Part B: Course and Faculty relationships

Part C: Student, Course, and Enrollment relationships

Part D: Department-based JOIN queries

Part E: Filtering and sorting JOIN results

Part F: Analytical queries using JOINs and aggregate functions

## 🛠️ Technologies Used

SQL

RDBMS (Oracle SQL )

## ⚠️ Rules & Constraints

Only INNER JOIN is allowed

Table structures must not be modified

JOIN queries are strictly read-only

Realistic sample data may be inserted if required

## ✅ Learning Outcomes

After completing this lab, students will be able to write efficient JOIN queries, understand table relationships clearly, and analyze data across multiple tables in a structured and optimized way.
